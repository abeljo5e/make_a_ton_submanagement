# Architecture Decision Records (ADRs)

Use an ADR when the team makes a decision that affects multiple modules or is expensive to reverse.

Create files as `0001-short-title.md`, `0002-short-title.md`, etc.

Examples:
- Authentication strategy (JWT vs secure cookie session).
- UUID vs integer IDs.
- Money/currency representation.
- Billing scheduler strategy.
- Deployment provider.
- Product/plan price semantics.

Keep decisions short and record alternatives considered.
