# Definition of Done

A task is done only when:
- [ ] Acceptance criteria are met.
- [ ] Code follows the agreed structure and naming conventions.
- [ ] Backend validation and authorization are implemented where relevant.
- [ ] Tests are added or updated and pass.
- [ ] Frontend states (loading, empty, error, success) are handled where relevant.
- [ ] No secrets or local-only paths are committed.
- [ ] API/database changes are documented.
- [ ] Migrations are included when schema changes.
- [ ] The feature works with the latest integrated `main`.
- [ ] A reviewer has approved the PR.
- [ ] Relevant README/docs are updated.
